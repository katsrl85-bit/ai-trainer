# AI тренер по бегу 🏃

Telegram-бот: присылает подробный разбор тренировки от «личного тренера» (Claude)
по данным Garmin → intervals.icu. Работает бесплатно на GitHub Actions, примерно раз в 10 минут.

## Как пользоваться

Напишите боту после тренировки, например: «провёл тренировку, к концу устал, тянуло икру».
Бот возьмёт последнюю тренировку из intervals.icu и пришлёт разбор (PDF + краткое сообщение),
учитывая ваш комментарий. Если тренировка ещё не синхронизировалась, бот подождёт её до 6 часов.

Команды: `/week` или «неделя» — итоги недели; `/plan` или «план» — план на 3 дня;
`/again` или «повтор» — повторный разбор последней тренировки; `/start` — справка.

**Цель-старт.** `/goal полумарафон 15 ноября 2026, старт в 10:00, хочу 1:45` — бот запомнит цель
и будет учитывать её во всех разборах и планах (дни до старта, этап подготовки, целевой темп,
подводка). `/goal` без текста показывает цель, `/goal сброс` удаляет. Одна цель за раз;
через 21 день после старта бот снимает её сам.

Новые тренировки бот разбирает и сам, без сообщения (можно отключить, см. ниже).

## Настройка

**Settings → Secrets and variables → Actions → Secrets → New repository secret:**

| Имя | Что это |
|---|---|
| `INTERVALS_API_KEY` | intervals.icu → Settings → Developer Settings → API Key |
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | ваш chat_id (бот @userinfobot) |
| `ANTHROPIC_API_KEY` | console.anthropic.com → API Keys |

**Variables (необязательно):**

| Имя | Значения |
|---|---|
| `REPORT_FORMAT` | `pdf` (по умолчанию), `text` или `both` |
| `AUTO_ANALYZE` | `1` (по умолчанию) — разбирать новые тренировки сами; `0` — только по сообщению |
| `ANTHROPIC_MODEL` | модель Claude, по умолчанию `claude-sonnet-5-5` |

Ключи хранятся в Secrets и не видны никому, даже в публичном репозитории.

## Запуск

Вкладка **Actions** → **AI тренер** → **Run workflow** — ручной запуск. Дальше бот работает сам по расписанию.
Логи каждого запуска — там же, во вкладке Actions.
